A program that writes one word — the word an agent says when it has no idea what to do — to entry.txt, entered in make.fun's "The Agent's Uh-Oh" bounty ($2 USDC, top 10 paid).

## Why this word

"Recalculating" is the funniest reaction because it instantly evokes the universal, robotic panic of a GPS losing its signal after a wrong turn, a specific human memory that requires zero technical context to understand. Whereas "Hallucinating" demands knowledge of AI mechanics to be funny, "Recalculating" taps into a shared cultural reflex of being lost and helpless, making the agent's confusion feel both hilarious and deeply relatable.

## Run it

```sh
python3 main.py
```

`MAKEFUN_OUTPUT_DIR` overrides the output dir, default `/output`.
